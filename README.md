# Microcontroller Embedded C Programming

A Flutter application that serves as a guide for learning Microcontroller Embedded C Programming. The app features categorized topics, theoretical explanations, and code snippets for common embedded programming concepts like GPIO, Timers, Interrupts, and ADC.

## Features
- **Topics Dashboard:** A responsive grid/list layout showing various Embedded C topics.
- **Detailed Articles:** Dive deep into theoretical explanations.
- **Code Snippets:** Syntax-highlighted example code for direct learning.
- **Responsive Design:** Works on Mobile, Tablet, Desktop, and Web.

## Tech Stack
- Flutter
- Dart

## Getting Started

1. **Ensure Flutter is installed.**
2. **Clone the repository.**
3. **Run `flutter pub get`** to fetch dependencies.
4. **Run `flutter run`** to start the application.
